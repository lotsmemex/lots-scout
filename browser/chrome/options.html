如何免费申请 OMDb key
  1. 打开 omdbapi.com/apikey.aspx。
  2. Account Type 选 FREE!（每天 1,000 次）。
  3. 填写 Email 和 Name；Use 写一句用途，例如 Personal favorites。点 Submit。
  4. key 会发到邮箱，先点邮件里的激活链接，key 才能用。
  5. 把 key 粘贴到上面的输入框，点「保存到 Mac」，保存后点「测试」。

OMDb 数据只限非商业使用，并需注明来源 OMDb。key 只交给你 Mac 上的收录服务保管，扩展不保存。

模型只在你的 Mac 上运行，扩展不保存任何模型密钥。

权限：当前标签页（仅在你点击时）、右键菜单、侧边栏（显示收录进度）、本机 127.0.0.1；批量收录网页时，按站点另行请求该站 HTTPS 访问权限（可选，可在 Chrome 扩展设置里撤销）。不读取 Cookie、浏览记录、表单或其他标签页。
